# String Input C++ Program

## Overview
This is a simple C++ console application that:
- asks the user for two strings
- concatenates them
- prints the result
- repeats this process 3 times

## Files
- [string-input.cpp](string-input.cpp): C++ source code
- [pseudocode.txt](pseudocode.txt): pseudocode for the program

## Requirements
- C++ compiler (g++ or clang++)
- macOS, Linux, or Windows terminal

## Build
```bash
g++ -std=c++17 string-input.cpp -o string-input
```

## RUN

```bash
./string-input
```
